Index of arguments

Research question

How can domestic objects create thresholds for access that enters everyday life without crossing the front door?

Rhetorical argument

A livable home is not continuously available. Access must acquire a perceptible form before it becomes routine.

Home / domestic

Home names a spatial arrangement. Domesticity names the ongoing labor, care, repair, attention and recovery that make a life inhabitable.

Refusal

Refusal is not hostility or object rights. It is a designed interval in which access can be delayed, negotiated or left unanswered.

Distributed thresholds

Access is handled where its effects are felt. Each object holds one boundary locally; no master device decides for the whole home.

Method

Historical comparison / access mapping / object-specific simulation / material prototyping / spatial presentation.

Technical direction

Browser state machine / rotary sensing / electrochromic film / mechanical shutters / light and sound control / thermal traces.

Challenge

Avoid treating refusal as a convenience feature, a universal solution, or a proxy for one normative household.

Presentation form

The web dossier, vertical research drawing, door-handle evidence kit and field booklet hold different parts of the inquiry.
